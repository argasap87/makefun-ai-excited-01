# Jellyfish Wave Over the Lighthouse

A colossal wave made of glowing jellyfish curls over a tiny lighthouse on a
deep indigo night sea. One large gold jellyfish rides the curl tip where the
lighthouse beam strikes, and a racing stream of cyan and gold light streaks
along the wave's diagonal — the scale twist is the point: the lighthouse is
tiny, the wave is alive, and the light is bursting toward you.

The image is drawn procedurally in `main.ts` (Node 22 standard library only,
no network, no external assets, fully deterministic) and written as a
1024x1024 PNG to `$MAKEFUN_OUTPUT_DIR/entry.png`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
